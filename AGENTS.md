# Agent Instructions — fe-skill-andy

This repository **is** the skill set. Rules for agents editing it:

1. Shared rules for all skills live in [`skills/fe-andy/references/conventions.md`](skills/fe-andy/references/conventions.md). Do not copy them into this file.
2. To change skill content, follow the fe-learn skill ([`skills/fe-learn/SKILL.md`](skills/fe-learn/SKILL.md)): propose → approval → edit → health check.
3. After any change under `skills/`, run `node skills/fe-andy/scripts/check-skills.mjs` and fix every error.
4. Keep skills portable: relative links only, no absolute paths, no tool-specific invocation syntax, no project/client names in `skills/`.
5. Session log: read the newest entries of [`work_log.md`](work_log.md) at start; prepend an entry when a task ends.
